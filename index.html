Cómo funciona Cuentas Claras

Calculadora de notas y promedio académico

Registra la nota y el porcentaje de cada evaluación para calcular el acumulado de una materia. Define tu nota objetivo y consulta cuánto necesitas en las evaluaciones pendientes para aprobar.

Horarios de clases y faltas de asistencia

Organiza las materias por semestre, consulta tu horario semanal y registra las faltas. Configura las fechas del semestre y el porcentaje máximo de inasistencias para seguir tu asistencia.

¿Necesito una cuenta para empezar?

Puedes agregar tus materias manualmente y guardar tus datos en este navegador sin registrarte. Descarga una copia JSON para restaurarla en otro dispositivo o conservar un respaldo.

¿La importación con inteligencia artificial es obligatoria?

Es opcional. Para leer capturas de horarios o notas puedes copiar un prompt para tu IA personal o conectar una API compatible. Su uso puede generar cargos del proveedor.
